Device & rhythm

Let the soil set the pace.

The measurement interval includes awake time. Each window must fit within half the interval and contain at least five radio events. A long connection postpones the next sample.

Low-battery behavior

Firmware 0.2.11 tests a 0.8 V input cutoff; older firmware stops at 2.2 V. Low-voltage operation requires a healthy regulated rail. Voltage is not a precise battery percentage.

A sensor that sleeps

The browser can connect only while the sensor is advertising. A sleeping sensor cannot be woken by Bluetooth.
